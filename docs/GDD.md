# 政壇大亂鬥：遊戲設計文件（第一版）

## 1. 定位
- 搞笑二創同人網頁遊戲，台灣政壇人物 2.5D 亂鬥（參考小朋友齊打交的操作邏輯）
- 風格：高彩度像素插畫 + 政治梗；每位角色以**公開言論、名言、經典畫面、外型特徵**誇張化
- 原則：不寫真名、陣營盡量平衡、不捏造醜聞、不拿進行中的司法案件開玩笑

## 2. 畫面流程
開場插畫輪播（5 張，可跳過）→ 首頁（PRESS ENTER）→ 操作說明 → 選模式＋難度 → 選角（單挑會再選對手）→ 選場地 → VS 畫面 → 對戰 → 結算（上榜輸入名字）→ 排行榜

## 3. 戰鬥系統
- 2.5D 座標：x 左右、z 前後、y 高度。攻擊需要 z 軸對齊才打得到
- 血量 420（受防禦倍率影響）；氣力 0～100，自然回復＋打人／被打都會累積
- 一般攻擊：三段連段（第三段擊倒）、跳躍攻擊、衝刺攻擊
- 防禦：只擋正面，扣 12% 傷害；大絕、摔技、全場技擋不住；連續擋太多會破防
- 擊倒後短暫無敵（倒地 → 起身）
- 技能：每個角色三招，採傳說對決式冷卻（2.5～12 秒），不耗氣；冷卻倒數顯示在手機按鈕／電腦版左下
- 大絕：氣力 100。全場只暫停 0.3 秒，接著頭像＋金句橫幅蓋在上方血條區約 1.6 秒，打鬥不中斷
- 打擊感：命中停頓（hitstop）、畫面震動、火花、傷害數字、連段數

## 3.1 小朋友齊打交為什麼好玩 → 我們怎麼做
| 好玩的原因 | 本遊戲的做法 |
|---|---|
| 招式好按：防＋方向＋攻，誰都按得出來 | 每個角色三招特技（防→前／上／下→攻），手機用「特」鍵＋搖桿方向 |
| 打擊有節奏：連打會晃、再打就倒 | 倒地值 fall：40 暈眩（可抓）、60 倒地；三段連段第三下必倒 |
| 抓人丟人超爽，還能拿人當武器 | 暈眩時走過去抓、揍、丟；被丟的人撞倒路上的人 |
| 撿東西打架：牛奶、石頭、球棒、箱子 | 便當、珍奶、標語牌、麥克風、雞蛋、議場椅子 |
| 防禦不是萬能 | 破防值：連續擋太多下會被破防 |
| 永遠有翻盤機會 | 可回復血量、低血量回氣變快、空中翻身、翻滾閃避 |
| 遠攻互剋 | 飛行道具互撞抵銷 |
| 多人混戰、誰都能打 | 四人亂鬥各自為戰，範圍技會掃到所有人 |

## 4. 模式
| 模式 | 規則 | 分數 |
|---|---|---|
| 單挑 | 1v1，99 秒 | 傷害×10 + 擊倒×3000 + 連段 + 勝利獎勵 |
| 四人大亂鬥 | 各自為戰，玩家倒下就輸 | 同上 |
| 連戰生存 | 每波回血 35%，第 4 波 2 敵、第 7 波 3 敵，敵人逐波變強 | 同上 + 過關獎勵，上排行榜 |

難度倍率：簡單 ×0.8／普通 ×1／困難 ×1.3

## 5. 角色
見 `js/characters.js`（資料）與 `js/moves.js`（招式）。新增角色的步驟：
1. 在 `characters.js` 加一筆資料（稱號、金句、能力、外型）
2. 在 `moves.js` 加 special / super
3. 在 `sprites.js` 的 `POSTER_POSE` 加海報姿勢
4. （之後）生圖放進 `assets/` 並登記 `manifest.json`

## 6. 後續規劃
- **第二階段：手機當搖桿**。電腦／電視開遊戲，大家用手機掃 QR Code 變成搖桿。用 WebRTC（PeerJS）點對點連線；`input.js` 的 Controller 已經是抽象介面，遠端搖桿只要寫一個新的 Controller 來源
- **全球排行榜**：Firebase Firestore（`js/config.js` 填設定即可）
- **劇情模式**：橫向卷軸清版，五關（立法院 → 造勢晚會 → 政論節目 → 夜市 → 總統府）
- **更多角色**：賴清德、蔡英文、沈伯洋、吳敦義、蔣萬安、謝龍介、黃國昌等（先列梗表審核再做）
- 夜市、總統府場景
