# 🏆 劇情模式「最快通關榜」設定步驟（約 5 分鐘）

成績會存進**你自己的 Google 試算表**（Google Sheets）。做完後把最後拿到的網址傳給 Claude，Claude 會把它接進遊戲再上傳。

---

## 1. 建立試算表

1. 打開 <https://sheets.new>，登入你的 Google 帳號，就會開一個新的空白試算表。
2. 把左上角的檔名改成 **政壇大亂鬥 排行榜**（名字可以隨便取，方便自己找就好）。

## 2. 貼上排行榜程式

1. 在試算表上方的選單點 **擴充功能 → Apps Script**，會開一個新分頁。
2. 左邊有一個 `程式碼.gs`（也可能叫 `Code.gs`）。把裡面原本的內容**全部刪掉**。
3. 打開這個資料夾裡的 `apps-script.gs`，**全部複製**，貼進去。
4. 按上方的 💾 **儲存**（或 Ctrl+S）。專案名稱可以取「排行榜」。

## 3. 部署成網址

1. 點右上角的藍色按鈕 **部署 → 新增部署作業**。
2. 點「選取類型」旁邊的 ⚙️ 齒輪，選 **網頁應用程式**。
3. 設定：
   - **說明**：隨意填，例如「排行榜」
   - **執行身分**：選「我」
   - **具有存取權的使用者**：選「所有人」。一定要選這個，其他玩家才能上傳成績。
4. 按 **部署**。
5. 第一次部署會要求授權：
   1. 按 **授予存取權**，選你的 Google 帳號。
   2. 會看到「Google 尚未驗證這個應用程式」。這是正常的，因為程式是你自己的。
   3. 點左下角的 **進階**，再點 **前往「排行榜」（不安全）**。
   4. 按 **允許**。這個權限只讓程式寫入**這一份**試算表。
6. 完成後會顯示 **網頁應用程式網址**，長得像這樣：
   `https://script.google.com/macros/s/AKfy................/exec`
   按 **複製**。

## 4. 把網址傳給 Claude

把那串結尾是 `/exec` 的網址貼到對話裡。Claude 會：
- 填進 `js/config.js` 的 `speedboardUrl`
- 實際測試上傳和讀取成績
- 上傳到 GitHub Pages

---

## 之後怎麼管理

- **看所有紀錄**：打開那份試算表。每次上傳的成績都是一列，有時間、暱稱、難度（easy／normal／hard）、通關秒數、角色。
- **刪掉不雅暱稱或可疑成績**：直接刪掉那一列，排行榜馬上就不會顯示。
- **清空重來**：刪掉第 2 列以後的資料，第 1 列的標題要留著。
- 同一個暱稱在同一個難度，只會顯示最快的那一次。
- 這些成績會被拒絕：
  - 三關全破時間少於 60 秒
  - 有開密技或測試模式（遊戲裡就不會讓你上傳）

## 注意

- 如果之後改了 `apps-script.gs`，要重新部署，網址不會變：
  1. 點 **部署 → 管理部署作業**。
  2. 點 ✏️ **編輯**。
  3. 版本選 **新版本**。
  4. 按 **部署**。
- 排行榜是公開的，有遊戲網址的人都看得到暱稱。
